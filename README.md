# AWS Lambda Managed Instances Walkthrough

Terraform-first walkthrough for AWS Lambda Managed Instances — capacity provider, VPC, and how LMI differs from default Lambda.

**Site:** https://aws-lambda-managed-instance-walkthrough.johna.kiwi/

Companion modules: [jajera/terraform-aws-lambda-managed-instance](https://github.com/jajera/terraform-aws-lambda-managed-instance).

## Quick start

```bash
npm install

```

Open the local preview URL (usually http://localhost:4321/).
